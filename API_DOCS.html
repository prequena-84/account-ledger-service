Account Ledger Service (Core Bancario)

Documentación técnica de los endpoints internos (Protegidos por x-internal-key).

1. Módulo: Cuentas (Account)

Endpoint Propósito Params / Query Body (Request) Respuesta (Response)
POST /api/v1/accounts Crear nueva cuenta bancaria N/A { "account_id": "UUID", "currency": "USD", "available_balance": 1000 } HTTP 201: Objeto AccountEntity
GET /api/v1/accounts/:id Consultar saldo de cuenta id (UUID) en URL N/A HTTP 200: Objeto AccountEntity

2. Módulo: Reservas (Ledger Reservation)

Endpoint Propósito Params / Query Body (Request) Respuesta (Response)
POST /api/v1/reservations Reservar fondos (Bloqueo Pesimista) N/A { "transaction_id": "UUID", "account_id": "UUID", "amount": 100.50 } HTTP 201: Objeto ReservationEntity
GET /api/v1/reservations/:id Consultar estado de reserva id (UUID) en URL N/A HTTP 200: Objeto ReservationEntity
PATCH /api/v1/reservations/:id/status Actualizar estado (Confirmar/Compensar) id (UUID) en URL { "status": "CONFIRMED" | "COMPENSATED" } HTTP 200: Objeto ReservationEntity actualizado
